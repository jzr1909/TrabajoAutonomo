# Trabajo Autónomo - Programación Orientada a Objetos

Este repositorio contiene los ejercicios y prácticas realizadas durante el trabajo autónomo de **Programación Orientada a Objetos (POO)**.

El objetivo es almacenar y organizar los diferentes ejercicios desarrollados en Java, aplicando conceptos fundamentales de la programación orientada a objetos.

## 📁 Contenido del repositorio

### 1. Ejercicio1_POO_Empleado

En esta carpeta se encuentra el ejercicio de **Pago de Empleados**.

El programa permite:

- Registrar una cantidad determinada de empleados.
- Ingresar los datos de cada empleado.
- Asignar una categoría.
- Calcular la bonificación y el descuento según la categoría.
- Calcular el valor final a pagar.
- Calcular el valor total de los pagos.
- Almacenar los empleados utilizando estructuras de datos como `ArrayList` y `HashMap`.
- Mostrar la información de los empleados registrados.

En este ejercicio se aplican conceptos como:

- Clases y objetos.
- Encapsulamiento.
- Atributos y métodos.
- Getters y setters.
- `ArrayList`.
- `HashMap`.
- `JOptionPane`.

---

### 2. Ejercicio1_Herencia

En esta carpeta se encuentra un ejercicio desarrollado para practicar el concepto de **herencia en POO**.

El ejercicio trabaja con una clase principal de productos y una clase que hereda de ella para realizar procesos adicionales relacionados con descuentos.

Se aplican conceptos como:

- Herencia.
- Clase padre y clase hija.
- Encapsulamiento.
- Métodos.
- Getters y setters.
- `ArrayList`.
- `HashMap`.
- Cálculo de descuentos.
- Cálculo del precio final.
- Uso de `JOptionPane`.

La clase `ProductoDescuento` hereda características de la clase `Productos` y agrega funcionalidades relacionadas con el cálculo del descuento y el precio final.
